# Code of conduct

## The standard

Be respectful and assume good faith. Criticize code and ideas, not people. Accept that
maintainers make final calls on scope and direction, and that a declined contribution is
not a judgment of the contributor.

Unacceptable: harassment, personal attacks, discriminatory language, publishing others'
private information, and sustained disruption of discussions.

## Scope

This applies in issues, pull requests, and any other space where someone is representing
this project.

## Enforcement

Report concerns to **plus@42min.us**. Reports are handled confidentially. Maintainers may
edit or remove contributions, and may block accounts, for behavior they judge
inappropriate.
